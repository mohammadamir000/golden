# میزبان آفلاین PS4 GoldenHEN

این پروژه یک رابط وب آزمایشی برای انتخاب نسخه فریمور PS4 و بررسی قابلیت ذخیره‌سازی فایل‌های وب برای استفاده آفلاین است.

> **توجه مهم:** این نسخه صرفاً پوسته و نمونه اولیه رابط کاربری است. فایل اکسپلویت، Payload یا خود GoldenHEN در آن قرار ندارد؛ بنابراین اجرای واقعی یا آنلاک بازی‌ها را انجام نمی‌دهد. برای تأیید سازگاری و اجرای واقعی، به کنسول PS4 و فایل‌های معتبر و متناسب با فریمور نیاز است.

## امکانات فعلی

- رابط کاربری با حال‌وهوای داشبورد پلی‌استیشن ۴
- نمایش و انتخاب نسخه‌های مختلف فریمور
- ساختار اولیه برای ذخیره فایل‌های سایت در کش مرورگر
- طراحی واکنش‌گرا برای نمایش در موبایل و دسکتاپ
- قابل انتشار به‌صورت سایت استاتیک در GitHub Pages

## انتشار روی GitHub Pages

1. فایل‌های پروژه را در یک مخزن (Repository) جدید GitHub بارگذاری کنید.
2. مطمئن شوید فایل `index.html` در ریشه مخزن قرار دارد.
3. در مخزن به مسیر **Settings → Pages** بروید.
4. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب کنید و **Save** را بزنید.
6. پس از پایان انتشار، آدرس GitHub Pages در همان صفحه نمایش داده می‌شود.

## اجرای آزمایشی

برای آزمایش رابط، فایل `index.html` را در مرورگر باز کنید. برای بررسی Service Worker و کش آفلاین، سایت را از یک نشانی HTTPS مانند GitHub Pages باز کنید؛ Service Worker معمولاً در فایل محلی `file://` فعال نمی‌شود.

## وضعیت پروژه

این نسخه برای آزمایش رابط و روند انتشار ساخته شده است. کش‌شدن رابط وب به‌تنهایی به معنی کش‌شدن اکسپلویت یا آماده‌بودن GoldenHEN نیست. عملکرد واقعی روی PS4 هنوز آزمایش نشده است.
