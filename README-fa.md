# PS4 Golden Host — نسخه ۲

## امکانات
- انتخاب و ذخیره نسخه فریمور در مرورگر
- نمایش وضعیت آنلاین و آفلاین
- ذخیره فایل‌های رابط با Service Worker
- بخش نمایشی Payloadها و دکمه اجرای آزمایشی
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## نکته مهم
این نسخه شامل اکسپلویت، فایل GoldenHEN یا Payload اجرایی نیست. دکمه «اجرای آزمایشی» فقط پیام توضیحی نمایش می‌دهد و روی کنسول چیزی اجرا نمی‌کند. انتخاب فریمور نیز سازگاری را تأیید نمی‌کند. اجرای واقعی فقط با PS4 و فایل معتبر و سازگار قابل بررسی است.

## آپدیت GitHub
1. ZIP را استخراج کنید.
2. فایل‌های داخل پوشه را در ریشه مخزن `golden` بارگذاری و فایل‌های هم‌نام را جایگزین کنید.
3. Commit changes را بزنید.
4. پس از انتشار، سایت را باز کنید: https://mohammadamir000.github.io/golden/
5. اگر نسخه قبلی دیده شد، صفحه را در حالت ناشناس باز کنید یا کش مرورگر را پاک کنید.

## فایل‌ها
- `index.html`: ساختار صفحه
- `style.css`: ظاهر سایت
- `app.js`: انتخاب فریمور و دکمه‌ها
- `sw.js`: کش آفلاین
- `manifest.webmanifest`: تنظیمات وب‌اپ
