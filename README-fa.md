# AmirGem Host V4

داشبورد چندفریموری PS4 با دسته‌بندی مسیرهای منتشرشده در PS4 AIO و فهرست رسمی GoldHEN v2.4b18.

## تفاوت مهم
- «مسیر هاست» یعنی یک پروژه عمومی برای آن بازه، مسیر ورودی/اکسپلویت را منتشر کرده است.
- «پشتیبانی GoldHEN» فقط نسخه‌هایی است که در Release رسمی GoldHEN v2.4b18 فهرست شده‌اند.
- این دو یکی نیستند؛ برای نمونه مسیر Slopkit Relapse در PS4 AIO برای 13.02–13.52 به معنی پشتیبانی رسمی GoldHEN نیست.

## مسیرهای ثبت‌شده
- 5.05: هاست اختصاصی
- 6.72: هاست اختصاصی
- 7.00–8.52: PSFree + Lapse
- 9.00–9.60: PSFree + Lapse
- 6.00–11.02: CSSFontFace + Lapse/Poops (مسیر جایگزین در بازه هم‌پوشان)
- 11.00–13.00: Slopkit + Lapse/Poops
- 13.02–13.52: Slopkit Relapse

## فریمورهای رسمی GoldHEN v2.4b18
5.05، 6.71، 6.72، 9.00، 9.60، 10.00، 10.01، 10.50، 10.70، 10.71، 11.00.

## محدودیت این بسته
این نسخه داشبورد و مسیریاب سازگاری است. فایل‌های اکسپلویت/هن و payload اجرایی را داخل خود ندارد و اجرای واقعی روی PS4 انجام نشده است. برای استفاده واقعی باید فایل‌های upstream، نسخه‌ها، مجوزها و hashها بررسی و سپس روی کنسول آزمایش شوند.
